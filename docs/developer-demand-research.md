# Developer demand signals for Houston

Research checked September 13, 2026. These are individual public user reports and product documentation, not a representative survey or measured Houston demand. Recommendations are product hypotheses.

1. **Agent completion and needs-input signals.** Developers request notifications when long-running work finishes, approval is required, or an agent is blocked, including click-through to the relevant conversation and separate notification preferences. [Claude Code issue #26581](https://github.com/anthropics/claude-code/issues/26581) is an open feature request; [#29928](https://github.com/anthropics/claude-code/issues/29928) adds reports from VS Code and JetBrains users. Houston hypothesis: session cards with running, needs-input, done, and failed states; clicking returns to the relevant session. These reports describe particular environments and do not establish that all current Claude clients lack notifications.

2. **Proactive quota alerts, followed by pace.** A CodexBar user describes starting a large task and exhausting quota halfway through, requesting customizable macOS alerts at low remaining quota and two alarm levels. [Issue #617](https://github.com/steipete/CodexBar/issues/617), filed March 29, 2026, is closed. Separately, a user asks to expose usage-versus-expected pace consistently across providers and directly in the menu bar. [Issue #807](https://github.com/steipete/CodexBar/issues/807). Houston hypothesis: configurable threshold notifications first, reset notifications second, then an estimated “at this pace” indicator. Competitor [configuration documentation](https://github.com/steipete/CodexBar/blob/main/docs/configuration.md) now documents low-quota and reset hooks; this is existing competitor functionality, not proof these requests remain unimplemented. History can support pace but is less directly supported by these requests.

3. **Clearly separated accounts.** A CodexBar user explicitly asks to switch between two accounts when one hits its limits. [Issue #192](https://github.com/steipete/CodexBar/issues/192), filed January 16, 2026, is closed. A newer request seeks a compact account selector for multiple Claude subscriptions. [Issue #3382](https://github.com/steipete/CodexBar/issues/3382), filed September 2, 2026. Houston hypothesis: labeled work/personal accounts with independently displayed quota, then explicit account selection. Demand evidence is narrower than the first two recommendations; accurate account identity matters more than automatic switching.
