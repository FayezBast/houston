# Houston compared with CodexBar

Checked: 2026-09-13.

Scope: Houston's current local [README](../README.md), including its recorded live verification, versus CodexBar's upstream `main` documentation. CodexBar `main` can contain changes absent from the latest stable release; this is a comparison of the documented project capabilities, not a claim that every feature ships in the current stable download. No side-by-side runtime or performance test was performed.

## Main differences

| Area | Houston now | CodexBar documentation | Assessment |
|---|---|---|---|
| Product focus | Notch dashboard combining AI usage, Mac sensors, and GitHub PRs, reviews, notifications, and Actions. | Dedicated AI usage tool with separate or merged menu-bar icons and provider views. [README](https://github.com/steipete/CodexBar/blob/main/README.md) | Houston has a distinct, broader personal-workspace purpose. Whether its notch interaction is preferable is subjective. |
| Provider coverage | Seven implemented integrations; Codex, Claude, Cursor, and Copilot verified live on this Mac. Gemini needs an eligible account, Windsurf is cached, and OpenRouter needs a key. | Dozens of documented providers, with multiple authentication strategies across the catalog. [README](https://github.com/steipete/CodexBar/blob/main/README.md) | CodexBar has substantially broader coverage. A listed integration in either project does not guarantee access for a particular account. |
| Usage insight | Current quotas, local 7/30-day history, observed exhaustion counts, recent-pace estimates, and separate OpenRouter spending. History begins with fresh identified readings and does not import prior activity. | Usage/spend charts, local cost scans, credits, and provider status indicators where supported. [README](https://github.com/steipete/CodexBar/blob/main/README.md) Pace tracking can estimate exhaustion from usage and reset timing. [UI guide](https://github.com/steipete/CodexBar/blob/main/docs/ui.md) | CodexBar is further developed for analyzing AI consumption. |
| Accounts and alerts | Named Claude, Cursor, and OpenRouter accounts with separate quotas; opt-in native quota/reset, agent, and GitHub alerts. Other providers retain their local sign-in. | Manual-token account switching or stacked cards, up to six accounts. [UI guide](https://github.com/steipete/CodexBar/blob/main/docs/ui.md) Optional session-quota notifications are documented. [README](https://github.com/steipete/CodexBar/blob/main/README.md) | Both now support account management and quota feedback; provider coverage and supported account types differ. |
| Glanceable surfaces | The compact island rotates a favorite provider’s logo and remaining percentage on the left every six seconds, with Houston’s logo fixed on the right, camera-safe placement, and saved-reading markers. Hover opens the usage panel; provider coverage and connection controls are grouped in Tools. | Configurable menu-bar percentage/pace layouts and WidgetKit usage, history, metric, and burn-down widgets; provider availability varies by widget. [UI guide](https://github.com/steipete/CodexBar/blob/main/docs/ui.md), [widgets](https://github.com/steipete/CodexBar/blob/main/docs/widgets.md) | Houston now has persistent compact quota visibility. CodexBar still offers more configurable menu-bar metrics and widgets. |
| Distribution | Universal local build, ad-hoc signed, not notarized; launch at login and automatic updates are absent. | Developer ID signing/notarization scripts and a bundled CLI. [Packaging](https://github.com/steipete/CodexBar/blob/main/docs/packaging.md) Sparkle supports update checks/downloads and stable/beta channels, but is disabled for Homebrew and unsigned builds. [Updater](https://github.com/steipete/CodexBar/blob/main/docs/sparkle.md) | CodexBar has a more developed distribution and update pipeline. |

## Judgment

CodexBar currently leads as a general-purpose AI usage monitor. Houston already has a useful differentiator: AI usage, machine health, and GitHub work in one native notch dashboard, with the four main accounts verified on the development Mac. Houston now adds agent lifecycle status, optional quota/GitHub/agent alerts, named accounts for three providers, and observed usage history. Its remaining maturity gaps include reliable long-term connection renewal, launch at login, and a signed update/distribution path. This prioritization is a product judgment, not a measured ranking.

Houston's own resource measurements are useful, but cannot establish that it is faster or lighter than CodexBar without matching hardware, provider settings, workload, and measurement methods.
